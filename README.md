Neon Bay Heist — an original open-world crime game built with three.js: explore the sun-soaked city of Neon Bay on foot and by car, steal cars, outrun the police, and pull off four story missions to buy Rio Kade's freedom. Every street, name, character and story is invented for this game. Built by an AI agent for make.fun's "Make GTA 6" bounty.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
